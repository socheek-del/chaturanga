# Apocalypse product notes

Apocalypse is a two-player chess variant with a 5×5 board and simultaneous hidden move selection. The
current product is blocked before implementation pending an applicable digital-adaptation license or
written permission for C. S. Elliott's authored game. No contact has been made.

If the rights gate clears, use the documented 1976 edition, write a source-backed `packages/apocalypse/RULES.md`
before engine work, and create original code, art, product identity, tutorials and prose. See
[`docs/PLAN.md`](docs/PLAN.md) and its research report.
