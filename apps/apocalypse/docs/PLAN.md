# Apocalypse plan

## Status

Blocked before implementation while the project's digital-adaptation rights remain unverified. No rights
holder has been contacted.

## Selected edition

Use C. S. Elliott's 1976 5×5 simultaneous-move edition. Each side starts with two Horsemen (knights) and
five Footmen (pawns). This is the edition described by the catalog and the surviving rules summaries.
Available sources do not provide participation data comparing Apocalypse with other variants, so there is
no popularity claim.

## Rights gate

The game is a named modern authored title. The sources identify C. S. Elliott as creator and 1976 as its
creation date, but no applicable digital-adaptation license or written permission for this project was found.
The repository's rights gate therefore blocks faithful product implementation. No contact was made; do not
reuse another adaptation's text, board image or identity.

See [`reports/Apocalypse rules adoption and rights.md`](reports/Apocalypse%20rules%20adoption%20and%20rights.md).
