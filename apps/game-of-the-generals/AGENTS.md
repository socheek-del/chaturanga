# Game of the Generals product notes

Game of the Generals is a two-player hidden-rank board game with an automated arbiter. The product is
blocked before implementation until an applicable digital-adaptation license or written permission is
documented. No contact has been made.

If rights clear, implement only the selected documented rules in an original app. Keep rank information
private per seat and validate challenges in the server. See [`docs/PLAN.md`](docs/PLAN.md) and its report.
