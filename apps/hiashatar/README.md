# Hiashatar

Hiashatar is a 10×10 Mongolian chess game with two bodyguards per side. Learn its rules in the interactive field guide, play locally or against the computer, and invite a friend to a private online room.

Read the edition and implementation choices in `packages/hiashatar/RULES.md`. For development ports, tests, the bot, and Melon deployment, see `AGENTS.md` and `docs/PLAN.md`.
