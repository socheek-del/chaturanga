# Hnefatafl

## Selected ruleset

Use Copenhagen 11×11 as the documented modern tournament standard. The evidence establishes tournament
use, but not a worldwide popularity ranking. Copenhagen is distinct from Fetlar and historical weak-king
reconstructions. Its defining rules include shield-wall captures and exit forts. The cited report and source
notes are stored in this product's docs folder.

Before engine work, transcribe the exact 11×11 setup and resolve edge-fort adjudication, repetition, and draw
conventions against the tournament source. Preserve attacker/defender asymmetry, king escape/capture,
throne/camp rules and all shield-wall conditions in the rules contract and interactive tutorial.

## Rights gate

Hnefatafl is blocked before implementation under the repository's rights requirement. Aage Nielsen, Adam
Bartley and Tim Millar outlined Copenhagen rules in 2012; the primary rules page says all rights reserved and
provides no digital-adaptation license. Independent mechanics-only implementation may be possible in some
jurisdictions with original content, but this does not establish worldwide clearance or satisfy the repo's
requirement for applicable permission/license covering a faithful digital project. The AGPL license on an
existing engine covers code, not the rules contributors' text, diagrams or branding. Obtain applicable
permission/license and clear the name before implementation/public branding. No contact was sent.
