# Martian Chess plan

## Status

Blocked before implementation until written digital-adaptation permission is documented. No publisher contact has been made.

## Selected edition

Use the current two-player base edition from Looney Labs. The publisher documents the game as designed by Andrew Looney, created in 1995, first published in 1996, and currently available in Pyramid Arcade. The roadmap selects the two-player profile; available sources do not compare adoption rates across all player counts or equipment variants.

## Rights gate

Looney Labs' official electronic-games policy says a developer creating a freeware electronic version should request permission before making it available online; its stated terms also require a faithful adaptation and promotion of the physical game. This project has no written permission, so implementation must remain blocked. No contact has been made. If permission is later granted, record its scope and satisfy its promotion terms before release.
