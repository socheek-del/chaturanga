# Altai Shatra

An English PWA for the 62-field Altai tournament game: learn the rules, play a bot, play over the board, or invite a friend to a private room.

The selected 1983 Shatra Code form and its source conflict are documented in [`packages/shatra/RULES.md`](../../packages/shatra/RULES.md). Product decisions and verification are in [`docs/PLAN.md`](docs/PLAN.md).

Run `npm run dev:shatra` from the repository root. The web app uses ports 5210 and 8810. Run `npm run e2e -w apps/shatra/web` for browser coverage.
