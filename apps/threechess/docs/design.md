# Midnight Ring

Three players should be able to read the board at a glance: this design gives the three seats distinct
accents and keeps the 96 cells calm enough to scan. A deep blue-charcoal shell frames parchment and muted
green squares; White uses warm ivory, Black uses slate, and Red uses vermilion. A thin three-orbit mark carries
the ring idea into the home screen. The interface uses a restrained serif for large headings and system sans
for controls and move details.

The game screen keeps the active seat and all three player states above the board, with a move log beside it
on wide screens and below it on phones. Check, legal destinations, captures and the last move use separate
signals so one state does not carry the whole board. Buttons retain keyboard focus indicators and touch-sized
targets.

This is the shipped proposal; it has not been reviewed by the owner.
